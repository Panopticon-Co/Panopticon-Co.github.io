Methodology

How these numbers were counted

  • Non-merge commits on each repository's default branch, snapshot of 7 November 2026.
  • History shared between the detection engine and the Manager (48 commits) is counted once, under the detection engine.
  • Lines exclude vendored, generated, binary and lock files, including the generated vmlinux.h, ML result dumps and bundle manifests. A frontend mirror repository counts commits but no lines, because its content duplicates another repository.
  • "Code lines" count source files only (C/C++, Python, JavaScript, shell, CMake, SQL, HTML/CSS and YAML), not Markdown or JSON.
  • Commits made under Rishi Bose's Git identity on or after 1 October 2026 are credited to Aryan Sokhi, to whom the team attributes that work; earlier commits stay with Rishi Bose. Git history itself is unchanged.
  • "Other identities" are author emails that do not map to a team member.
  • Commit and line counts measure activity, not the value or difficulty of the work.
